# SA Community Safety Toolkit

An open source, community-built collection of tools, data guides and resources that help people understand, prevent and report crime in South Africa.

> **This project is not a replacement for the police.** If you are in danger, call **10111** (SAPS) or **112** from a cellphone. To report crime anonymously, call **Crime Stop on 08600 10111**.

## What this project is for

- Helping communities understand **publicly available crime statistics** (for example, SAPS quarterly crime stats)
- Building **safe, privacy-respecting tools**: crime-trend dashboards, safety checklists, neighbourhood watch templates, incident-report templates
- Sharing **clear guides** on how to report crime and where to get help (SAPS, Crime Stop, GBV Command Centre 0800 428 428, community policing forums)
- Making data **easier to read** for journalists, researchers, NGOs and community groups

## What this project is NOT for

To keep everyone safe, the following are **not allowed** here:

- Naming, shaming or tracking individuals (no "wanted" lists, no photos of suspects, no home addresses)
- Vigilantism or anything that encourages people to take the law into their own hands
- Collecting personal information about victims, witnesses or suspects
- Unverified accusations or rumours

Read [SAFETY.md](SAFETY.md) before contributing.

## Getting started

1. Browse the `docs/` folder for guides (add yours!)
2. Look at the `data/` folder for public datasets and how they were sourced
3. Check the [Issues](../../issues) tab for things that need doing
4. Read [CONTRIBUTING.md](CONTRIBUTING.md) to learn how to help

## Project structure (planned)

```
docs/      Guides and how-tos
data/      Public, anonymised datasets (with sources)
tools/     Scripts, dashboards and templates
```

## Data sources

Only use data that is legally public and properly credited, such as:

- South African Police Service (SAPS) crime statistics
- Statistics South Africa (Stats SA) Victims of Crime Survey
- Other open government or academic datasets

## Privacy and the law

Contributors must respect the **Protection of Personal Information Act (POPIA)**. Never upload personal information. See [SAFETY.md](SAFETY.md).
